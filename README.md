# Werkstation

Workstation config and dotfiles. Automated with bashscripts galore.

## Installation
While installation is subject to change, current process is below
```bash
cd src/ && ./build.sh
```
Future state will publush a tar artifact and installation will be completed via url installion simliar to below
```bash
bash -c "$(curl -fsLS <URL>)" -- init --ARGS
```
